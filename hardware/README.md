I used FreeCad to design the components used in the project which were then 3D printed / laser cut

For laser cutting, 2 thicknesses of plywood are used, 4mm and 3mm

For 3d printing, I suggest using a harder plastic as most components need some rigidity, like the UI cover which has to handle load of encoder presses for instance

Lastly, I'm sure many will find some mistakes or flaws in the designs, but this is the first time I have undertaken a project with this many aspects. So just a heads up.
