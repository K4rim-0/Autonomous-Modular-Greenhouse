# Autonomous-Modular-Greenhouse
A system of modules intended to aid in indoors plant keeping

V 0.1

Abstract

Plants are susceptible to environmental condition shifts when young or when in weakened states. To help resolve this issue I Have devised a system to help manage the environmental conditions which the plant inhabits. The system sits at the boundary between climate controlled indoors environment and the tent (made of transparent plastic film or opaque reflective metal film) microbiome. This version is intended for plants which cannot handle the coldness of air-conditioned rooms nor the extreme heat and humidity of the outdoors.

Description
This model consists of:
•	The central control unit: a ~16*16*16 cm cube with temperature/ humidity and light sensor. OLED screen, rotary encoder, status led and ports to connect to other components.
•	Fan/ ventilation module: allows for venting of the microbiome when it gets too hot and/or humid.
•	Water handling unit: consists of water pump, atomizer, and soil moisture sensor. It is meant to control humidity and water the plant.
•	Grow light: uses 220 mains voltage from the control unit to provide light for plant at darker times.
•	Heat Mat: heats up the base of the plant (pot) and is meant to be used for the plants during their earl stages as seedling in a tray.
The user interacts with the system through the encoder by rotating and pressing it. This allows them to navigate the menu, which allows them to set parameters which will be maintained by the system.
The system can maintain a single grown plant or raise a batch of seedling in a tray
